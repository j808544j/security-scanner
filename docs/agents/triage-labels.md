# Triage labels

Use these default role names as the values on the ticket’s `Status:` line.

| Label | Meaning |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | The issue is specified and ready for an agent. |
| `ready-for-human` | The issue requires human implementation. |
| `wontfix` | The issue is closed without implementation. |
